## 恢复结果边界

本交付包含所有 DEX 可静态恢复的 Java 文本、全部 Smali、资源、资产和 native 库。源码中的控制流平坦化、短数组 XOR 字符串池及不可打印重命名属于编译后混淆，已在云端与混淆分析中逐项定位。JADX 输出用于阅读和审计，不等同于作者原始源文件，且 native ELF 不能转换为等价 Java 源码。
