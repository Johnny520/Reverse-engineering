## 1. 结论

- 模块的"云端"由两部分组成：**激活验证后台**（Cloudflare Workers 边缘函数）和 **VIP 白名单服务**（作者自建动态域名上的 JSON 名单）。
- "用户信息"指 **当前登录抖音账号的 `uid` 与 `nickname`**，由 Kevin 从抖音应用内运行时 Hook 取得，缓存到 `PPHook` 的静态字段，再作为激活请求参数发送到云端。
- 云端回传的是**授权结果**（激活成功/失败/已激活）与 **VIP 名单**，不是"从云端下载用户画像"。用户信息的**流向是"客户端 → 云端"**（上报绑定），云端回包只带授权状态。

   │
   ▼

## 4. 详细调用链

### 4.1 入口分发（`KevinHook`）

`handleLoadPackage(LoadPackageParam)` 按包名分发：

- 抖音 `com.ss.android.ugc.aweme` → `new DYHook()` 并注入 LoadPackageParam（`KevinHook.java:357` 的 `L27` 分支）
- 快手 `com.yxcorp.gifshow` → `KSHook`
- 小红书 `com.xingin.xhs` → `XhsHook`
- PixelLab `com.imaginstudio.imagetools.pixellab` → `Pexellad`
- TikTok `com.zhiliaoapp.musically` → 另一分支

### 4.2 抖音 MainActivity Hook（`DYHook`）

`DYHook.hookMainActivity(LoadPackageParam)` 对 `com.ss.android.ugc.aweme.main.MainActivity.onCreate(Bundle)` 注册回调 `DYHook$5`（`DYHook.java:58775`）。`DYHook$5$1` 是一个 `Runnable`（在 MainActivity 创建后投递），其 `run()`：

1. 取得 `Context`
2. 构造 `DYHook$5$1$1`（即 `PPHook.VerifyCallback` 的实现）
3. 经混淆 nest-bridge `androidx/appcompat/ۣۧۤۢ;->ۨ۟ۥۢ(Context, VerifyCallback)` 调用 `PPHook.checkVerification(context, callback)`（Smali：`DYHook$5$1.smali:561`）

即：**每次进入抖音主页即触发一次激活校验。**

### 4.3 当前用户信息读取（抖音侧）

`DYHook.getCurrentUserOnce(LoadPackageParam)`（`DYHook.java:48280`）通过 Xposed/DexKit 对抖音"获取当前登录用户"的方法注册回调。回调组 `DYHook$85$1` ~ `DYHook$90$1`（Smali 文件，如 `DYHook$90$1.smali:1147`）：

- 从抖音用户对象取出 **`uid`**，写入 `DYHook.iuserUid`
- 取出 **`nickname`**
- 经混淆 bridge `androidx/appcompat/ۣۧۤۢ;->ۤۧ۟ۨ(String, String)` 调用 `PPHook.updateCurrentDouyinUser(uid, nickname)`

多组回调覆盖了抖音不同阶段/入口提供当前用户对象的路径（如启动、登录态变化），保证 uid 尽可能实时。

### 4.4 PPHook 本地状态写入

`PPHook.updateCurrentDouyinUser(uid, nickname)`（`PPHook.java:7787`，Smali `PPHook.smali:12766`）：

1. 两个参数分别经 `normalizeValue`（去空白等）规范化
2. 写入静态字段 `sCurrentDyUid`、`sCurrentDyNickname`
3. 若 `sVipListLoaded == false` → 经 bridge 调用 `loadVipListFromCloud()`（Smali `PPHook.smali:12808`）

### 4.5 激活校验（`PPHook.checkVerification` / `activateCode`）

`checkVerification(Context, VerifyCallback)`（`PPHook.java:2204`）：

- `context == null` → 记日志"验证失败: context 为 null"
- 检查登录态（`sCurrentDyUid` 非空、上下文有效），否则走 `m7260(context, "❌ 请先登录抖音", "未检测到有效的抖音账号信息", false, callback)`（失败弹窗）
- 否则进入激活流程

`activateCode(Context, code, VerifyCallback)`（`PPHook.java:2133`）：

1. 切到主线程弹"🔐 输入激活码"输入框（提示"激活码将绑定此账号"）
2. 后台线程执行 `lambda$11`（Smali `PPHook.smali:4788`）发起网络请求

**请求构造**（Smali `PPHook.smali` 内 `RunnableC06612` / `lambda$11` 区段，约 `PPHook.java:909-1216`）：

- 方法：POST
- URL：`https://tg-verify-api.kevin0529422.workers.dev/activate`
- Body：JSONObject，键含 **`uid`**（解码字符串池 key `9`，`PPHook.java:924`）与激活码字段（`activation_code`）
- Header：`User-Agent: Mozilla/5.0 (Android) KevinHook/1.0`（`PPHook.java:1141`），另有 Content-Type 等
- 失败重试：日志 `activateCode attempt=`、`, responseCode=`、`服务端返回空响应，HTTP=`、`activateCode 第 N 次异常`（`PPHook.java:1197/1205/1430/1629`）
- 读响应：`getResponseCode()` + 读 body（`PPHook.java:1188-1189`）

**响应解析**（`ActivateResult` 类 + `lambda$13`）：

- `PPHook$ActivateResult` 字段：`status:String`、`count:int`、`error:String`、`ok:boolean`（Smali `PPHook$ActivateResult.smali:17-23`）
- `lambda$13(ActivateResult, code, uid, nickname, Context, VerifyCallback)`（Smali `PPHook.smali:6964`）：
  - `status == "ok"`（字符串池 key `0x3d4`）→ 激活成功
  - `status == "already"`（字符串池 key `0x3d6`）→ 已激活
  - 否则 → 失败，展示 `error` 字段

**激活成功落盘**（`PPHook.java:7523 saveActivatedAccount` 等）：

- 写 MMKV `kevin_prefs` 的多个键（见 §5）
- 弹 `showVipWelcomeDialog`（"👑 🎉" VIP 欢迎，`PPHook.java:7754`，经 `m7245` 分发）

### 4.6 VIP 白名单拉取

`PPHook.loadVipListFromCloud()`（`PPHook.java:6914`）启动后台线程 `lambda$11`（`PPHook$$ExternalSyntheticLambda11`）：

- GET `https://111.kevin42.dpdns.org/vip_list.json`
- 解析 uid 集合 → `sVipUidSet`，置 `sVipListLoaded = true`
- 判定接口 `isVipUid(String uid)`（`PPHook.java:3371`）做成员查询
- 名单未加载完成时相关功能返回"名单尚未加载完成，暂不匹配"（`PPHook.java:3426`）

## 7. 附注：混淆对调用链的影响

本模块使用控制流平坦化 + 短数组 XOR 字符串池 + 不可打印字符重命名。方法名（`updateCurrentDouyinUser`、`checkVerification` 等）在 Smali 中保留，但**调用点被搬进伪装成 `androidx.*` 的 nest-bridge 类**（如 `smali/androidx/appcompat/ۣۧۤۢ.smali`、`smali/androidx/viewpager/ۣۢ۟ۤ.smali`）。追踪调用链时以"跨类 `invoke-static`"为准，不能只看 `kevin.*` 包内引用。云端 URL、VIP 名单 URL、存储键均为字符串池 XOR 编码，需按 `char[i] = shortPool[key+i] XOR xorVal` 还原。
