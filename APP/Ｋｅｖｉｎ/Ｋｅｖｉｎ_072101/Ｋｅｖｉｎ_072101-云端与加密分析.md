# Kevin_072101 云端与混淆分析

## 结论

- 包名为 `kevin.fun`，是 Xposed 模块；`assets/xposed_init` 指向 `kevin.fun.hook.KevinHook`。
- Manifest 声明 `INTERNET` 和 `ACCESS_NETWORK_STATE`，并把作用域列为抖音、小红书、快手、TikTok 与 PixelLab。
- 静态扫描确认 4 个明文业务 URL，完整清单见 `Ｋｅｖｉｎ_072101-urls.tsv`。
- Java 层未发现 `javax.crypto`、`Cipher.getInstance`、`SecretKeySpec`、`MessageDigest.getInstance`、`Mac.getInstance` 或标准 AES/RSA/DES 调用。
- 网络访问使用 OkHttp。`WebDAVConfig.java` 支持由使用者填写 WebDAV 服务 URL、用户名、密码与路径，配置保存在本地 MMKV；该 URL 为运行时输入，不是 APK 内置服务器地址。

## 网络调用位置

- `kevin/fun/hook/DYHook.java`：抖音相关下载、会话和媒体请求，使用 OkHttp `Request.Builder`、`newCall`、`execute`。
- `kevin/fun/hook/XhsHook.java`：小红书链接和下载请求，使用 OkHttp。
- `kevin/fun/hook/download/DownloadManager.java`：下载地址、请求头、重试与文件保存。
- `kevin/fun/hook/webdav/WebDAVConfig.java`：WebDAV 的 GET/PUT、Basic Authorization 请求头、备份和恢复。
- `kevin/fun/hook/VoiceAssistantHook.java`：语音相关 HTTP 请求。

## 已识别的代码混淆

该包没有检测到标准数据加密实现，但存在较强的代码混淆：

1. 控制流平坦化：大量方法用常量 XOR 与 `switch/goto` 表达普通分支，JADX 因而保留了低层跳转形式。
2. 短数组 XOR 字符串池：`kevin.fun.hook.audio.C1117.m8169(short[], int, int, int)` 对短数组指定片段逐项 XOR 后构造字符串；`WebDAVConfig`、`DYHook`、`XhsHook` 等类的静态 `short[]` 字段保存这类编码数据。
3. 不可打印符号与重命名：部分原类名被替换为不可打印字符，JADX 以 `Cxxxx` 或异常文件名表示。
4. 诱饵解码路径：`C1116.m8071`、`C1117.m8109` 等方法包含 `Math.random()` 参与的伪解码流程，其调用点均位于控制流平坦化的伪分支中，不能把其输出当作稳定业务明文。

因此，`restored-sources` 是完整的可读 Java 反编译副本，并保留可复核的短数组与控制流证据；它不是作者的原始 Gradle/Kotlin 工程。全部 Smali 与资源证据保留在 `apktool-full`。

## Native 库

APK 带有 `libdexkit.so` 与 `libmmkv.so`，覆盖 `arm64-v8a`、`armeabi-v7a`、`x86`、`x86_64`。它们分别属于 DexKit 和 MMKV 依赖；本次 Java 静态扫描没有发现业务 native 方法或自定义 native 云端协议入口。
