# QStory-Risk-Analysis

本仓库用于归档和说明对 `QStory_2.6.2-release.apk` 的逆向分析结果，重点记录其中疑似高风险行为、硬编码账号/接口、服务器通信逻辑以及相关证据文件。

## 项目说明

`QStory_2.6.2-release.apk` 经逆向分析后发现，该 APK 存在多处需要警惕的行为，包括但不限于：

- 从远程服务器获取黑名单数据；
- 自动扫描用户具有管理权限的 QQ 群；
- 在特定事件触发后匹配黑名单并执行踢人逻辑；
- 将踢人结果上报至远程接口；
- 上传用户登录相关信息；
- 存在本地高危逻辑，在特定身份状态下可能执行删除好友、退出群聊、删除本地目录等破坏性操作；
- 部分接口需要认证，无法直接通过普通 GET/POST 获取用户私有数据。

本项目仅用于安全研究、风险提示、证据留存和用户自查，不包含攻击、绕过认证、入侵后台或获取他人数据的内容。

## 关键结论

逆向结果显示，该 APK 的部分功能并非普通用户可见配置，而是由远程服务端控制。相关逻辑大致包括：

```text
请求服务器黑名单
        ↓
自动扫描用户管理群
        ↓
监听进群/消息事件
        ↓
匹配黑名单用户
        ↓
调用 QQ NT 内部接口执行踢人
        ↓
上报执行结果
```

此外，分析中还发现与用户身份、登录信息、IP、昵称、位置等字段相关的上传逻辑。部分接口返回 `401`，说明需要合法登录态或 token 才能访问用户相关数据。

## 已确认的部分接口

主要服务域名：

```text
https://qstory.suzhelan.top
```

已发现接口包括：

```text
GET  /user-v2/queryBlacklist
POST /user-v2/onKickBlacklist
POST /user-v2/doLogin
POST /user-v2/info
POST /user-v2/isLogin
POST /user-v2/refreshUserInfo
POST /user-v2/commitLoginInfo
```

其中：

- `queryBlacklist`：用于获取远程黑名单；
- `onKickBlacklist`：用于上报踢人结果；
- `commitLoginInfo`：用于提交用户登录/环境相关信息；
- `info`、`refreshUserInfo`、`isLogin` 等接口需要登录认证。

## 风险提示

如果你安装或使用过该 APK，建议：

1. 立即停用并卸载该模块；
2. 检查 QQ 账号、群管理权限和近期群操作记录；
3. 检查是否存在异常踢人、退群、好友删除等行为；
4. 保存 APK、日志、截图、报告和反编译文件作为证据；
5. 不要尝试绕过接口认证或访问他人数据，必要时通过正规渠道维权。
