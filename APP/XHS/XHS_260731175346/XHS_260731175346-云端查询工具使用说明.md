# query_xhs_user.py 使用说明

> 工具：XHS（小红书）用户云端公开数据查询工具
> 脚本：[query_xhs_user.py](query_xhs_user.py)
> 数据源：小红书网页版 `__INITIAL_STATE__`（用户资料 + 首页笔记列表）
> 依赖：Python 3.8+ 标准库（urllib / json / re），无需安装任何第三方包

---

## 一、准备

1. 安装 Python 3.8 或更高版本（Windows 可到 python.org 或微软商店安装）。
2. 确认命令行里能运行：

```bash
python --version
```

3. 进入脚本所在目录：

```bash
cd "XHS\XHS_260731175346"
```

4. 获取登录 Cookie（**必须**，未登录访问会返回 404）：

   - 浏览器打开并登录 [xiaohongshu.com](https://www.xiaohongshu.com)。
   - 按 `F12` → `Application`（应用）→ `Cookies` → `https://www.xiaohongshu.com`。
   - 复制 `a1`、`web_session` 等 Cookie 项（或直接把整个 Cookie 列表拼成一行）。
   - 之后通过 `--cookie` 传入，或设为环境变量 `XHS_COOKIE`。

---

## 二、用法

### 1. 查询单个用户（最常用，推荐带 xsec_token 的完整链接）

```bash
python query_xhs_user.py "https://www.xiaohongshu.com/user/profile/abcdef1234567890?xsec_token=xxxx&xsec_source=pc_feed" --cookie "a1=xxx; web_session=xxx"
```

输出示例：

```
============================================================
用户: 测试号  (xhs12345)
============================================================
认证: -           简介: 你好
性别: 女    领域: -
所在地: -    IP属地: 广东
关注: 12  粉丝: 3.5万  获赞与收藏: 89.1万  笔记数: 56
标签: 摄影
------------------------------------------------------------
笔记列表(共 2 条):
------------------------------------------------------------
[ 1] 视频 | 我的视频 | 赞 1234 藏 567 评 89 | 2024-03-10
[ 2] 图文 | 图文笔记 | 赞 100 藏 200 评 300 | -
```

字段含义：

| 字段 | 说明 |
| --- | --- |
| `认证` | 官方认证 / 企业认证，无则显示 `-` |
| `粉丝 / 关注 / 获赞与收藏 / 笔记数` | 自动格式化为 `万` 单位 |
| `IP属地` | 小红书展示的 IP 属地 |
| `赞 / 藏 / 评` | 单条笔记的点赞、收藏、评论数 |
| 日期 | 笔记发布时间（`2024-03-10` 格式） |

### 2. 只输入纯用户 ID（不带 xsec_token）

```bash
python query_xhs_user.py abcdef1234567890 --cookie "a1=xxx; web_session=xxx"
```

> 小红书对部分用户主页有风控，纯 ID 访问可能 404。遇到时请改用浏览器复制出的完整链接（含 `xsec_token`）。

### 3. 保存完整数据为 JSON

```bash
python query_xhs_user.py "https://www.xiaohongshu.com/user/profile/abcdef1234567890?xsec_token=xxxx" --cookie "a1=xxx; web_session=xxx" --json user_data.json
```

生成 `user_data.json`，包含：

```json
{
  "uid": "abcdef1234567890",
  "user": { "nickname": "...", "fansCount": "...", "..." : "..." },
  "notes": [
    { "id": "note1", "type": "video", "title": "...",
      "cover": "https://...", "likedCount": "...", "time": "2024-03-10",
      "xsecToken": "..." }
  ],
  "cursor": "分页游标",
  "source_url": "https://..."
}
```

### 4. 只输出笔记列表

```bash
python query_xhs_user.py "https://www.xiaohongshu.com/user/profile/abcdef1234567890?xsec_token=xxxx" --cookie "a1=xxx; web_session=xxx" --notes-only
```

### 5. 用环境变量提供 Cookie（避免每次敲长串）

```bash
# Windows PowerShell
$env:XHS_COOKIE = "a1=xxx; web_session=xxx"

# 之后直接运行即可
python query_xhs_user.py "https://www.xiaohongshu.com/user/profile/abcdef1234567890?xsec_token=xxxx"
```

## 三、命令行参数速查

| 参数 | 说明 |
| --- | --- |
| `target`（位置参数） | 小红书用户主页链接（推荐，含 `xsec_token`）或纯用户 ID |
| `--cookie` | 登录 Cookie，默认读取环境变量 `XHS_COOKIE` |
| `--json FILE` | 把完整数据（资料 + 笔记 + 游标）保存为 JSON 文件 |
| `--notes-only` | 只输出笔记列表，不输出用户资料 |

帮助信息：

```bash
python query_xhs_user.py --help
```

---

## 四、工作原理与局限

- 脚本请求用户主页 HTML，正则提取 `window.__INITIAL_STATE__`，从中读取用户资料与首页笔记列表。
- **只获取主页首屏笔记**（约 20 条左右）。更早的笔记需通过小红书 `edith` 接口分页拉取，该接口要求 `x-s` 签名（由前端 JS 生成），纯 Python 标准库难以实现，本工具未包含分页。
- 工具只读取**公开数据**，不含私密信息。

## 五、常见问题

| 问题 | 解决办法 |
| --- | --- |
| `python` 提示找不到命令 | 安装 Python 时勾选 "Add Python to PATH"，或改用 `py query_xhs_user.py ...` |
| 中文乱码 | 脚本已强制 UTF-8 输出；若终端仍乱码，设置环境变量 `PYTHONIOENCODING=utf-8` |
| `HTTP 404` | 未登录或链接缺少 `xsec_token`。请登录后复制完整主页链接，并传 `--cookie` |
| `网络错误` / 超时 | 检查网络能否访问 `xiaohongshu.com`（有时需代理）；脚本默认 30 秒超时 |
| `未解析到用户数据` | 说明请求返回的不是用户主页（如验证码/登录页）。检查 Cookie 是否过期，重新登录复制 |
| 只显示首页笔记 | 正常现象，见"工作原理与局限"；分页需 `x-s` 签名，暂不支持 |
| 返回数据是空/字段为 `-` | 某些用户字段小红书未公开或字段名随版本变化，属正常 |
