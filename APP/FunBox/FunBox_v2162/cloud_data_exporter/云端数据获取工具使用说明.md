# 用户云端数据导出工具

## 功能

`authorized_cloud_exporter.py` 使用用户提供的 OAuth/API Bearer Token 调用云服务的**文件列表接口**，将清单保存到本地；开启 `--download` 后可下载列表对象对应的文件。

- Token 只从环境变量读取。
- 导出目录不保存 Token。
- 每次运行都要求 `--confirm-user-authorized YES`。
- 默认下载只向与 `--base-url` 同一主机发送 Token；预签名下载链接通常不附加 Token。

## 文件

| 文件 | 说明 |
|---|---|
| `authorized_cloud_exporter.py` | Python 标准库实现，不需要安装第三方依赖。 |
| `云端数据获取工具使用说明.md` | 本使用文档。 |

## 使用前准备

1. 在云服务的官方开发者后台创建 OAuth/API 应用。
2. 由数据主体登录并完成授权，取得短期 Access Token。
3. 从该云服务 API 文档确认：文件列表路径、下载路径模板、返回 JSON 中的文件 ID 字段。
4. 使用 PowerShell 将令牌放入当前终端环境变量。令牌不写入脚本、命令历史、Markdown 或导出清单。

```powershell
$env:CLOUD_ACCESS_TOKEN = 'YOUR_SHORT_LIVED_ACCESS_TOKEN'
```

## 仅导出文件清单

下面以占位接口为例。将 `BASE_URL`、`LIST_PATH` 替换为你的云服务 API 参数。

```powershell
python .\authorized_cloud_exporter.py `
  --base-url 'https://BASE_URL' `
  --list-path '/v1/files' `
  --output '.\exported_cloud_data' `
  --confirm-user-authorized YES
```

输出文件：

```text
exported_cloud_data\cloud_inventory.json
```

支持两种列表返回格式：

```json
[
  {"id": "FILE_ID", "name": "example.txt"}
]
```

或：

```json
{
  "items": [
    {"id": "FILE_ID", "name": "example.txt"}
  ]
}
```

列表数组字段支持 `items`、`files`、`data`、`value`、`results`；对象 ID 字段支持 `id`、`file_id`、`uuid`、`key`。

## 预览数据而不写文件

```powershell
python .\authorized_cloud_exporter.py `
  --base-url 'https://BASE_URL' `
  --list-path '/v1/files' `
  --dry-run `
  --confirm-user-authorized YES
```

## 下载文件

当下载接口为 `/v1/files/{id}/content` 时：

```powershell
python .\authorized_cloud_exporter.py `
  --base-url 'https://BASE_URL' `
  --list-path '/v1/files' `
  --download-template '/v1/files/{id}/content' `
  --download `
  --limit 20 `
  --output '.\exported_cloud_data' `
  --confirm-user-authorized YES
```

若列表 JSON 已提供 `download_url` 或 `downloadUrl`，脚本直接使用该字段，`--download-template` 可省略。

## 参数

| 参数 | 说明 |
|---|---|
| `--base-url` | 云服务 API 根地址。 |
| `--list-path` | 文件列表 API 路径。 |
| `--download-template` | 下载路径模板，使用 `{id}` 代表文件 ID。 |
| `--token-env` | Token 环境变量名；默认 `CLOUD_ACCESS_TOKEN`。 |
| `--output` | 本地导出目录。 |
| `--download` | 开启下载。未加该参数时只写文件清单。 |
| `--limit` | 最多下载文件数；`0` 代表全部。 |
| `--dry-run` | 验证列表并显示前十条，不写本地文件。 |
| `--send-auth-to-download` | 同主机下载 URL 附加 Bearer Token。 |
| `--confirm-user-authorized YES` | 确认数据主体已经授权，必填。 |

## 输出结构

```text
exported_cloud_data/
├── cloud_inventory.json    # 列表原始记录与下载结果；不含 Token
└── files/                  # 开启 --download 后生成
    ├── 0001_example.txt
    └── ...
```

## 常见问题

- `401/403`：检查 Token 是否过期、Scope 是否包含文件读取权限。
- 列表格式错误：检查列表响应是否为数组，或是否含 `items/files/data/value/results` 数组。
- 下载失败：检查下载模板、文件 ID 字段和云服务的下载权限。
- 预签名 URL：脚本默认不向跨主机预签名 URL 附带 Bearer Token。
